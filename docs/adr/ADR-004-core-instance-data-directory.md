# ADR-004：Core 实例与数据目录所有权

- 状态：Proposed / 待 Core 确认
- 日期：2026-10-28
- 责任范围：Harness + Core 契约协作

## 背景
必须区分多个 Harness 连接同一 Core、多个 Core 进程共用数据目录、多个 Core 使用隔离目录。它们的风险和处理方式不同。

## 需要回答
- Core 的配置、日志、数据库和锁文件分别位于哪里？
- 多进程共享目录是否受支持？SQLite 写入和迁移如何处理？
- Core 是否提供实例 ID、健康检查、动态端口和优雅关闭？
- 第二个 Harness 连接同一 Core 时，哪些并发操作有保证？

## 暂定建议
Harness 不主动让两个受管 Core 使用同一数据目录；遇到冲突时停止新启动并诊断。仅关闭当前 Harness 明确拥有的进程。未知进程不自动终止。是否采用 Harness 单实例锁、独立目录或共享 Core，须依据现有产品和 Core 能力决定，不在此 ADR 中先验强制。

## 验证
重复启动、端口冲突、目录冲突、Core 崩溃重启、外部 Core 连接、两个客户端共享同一 Core。

## 重新评估条件
Core 明确发布多实例/共享目录支持策略或新的实例管理契约。
