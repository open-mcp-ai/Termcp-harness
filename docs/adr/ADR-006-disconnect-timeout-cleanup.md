# ADR-006：断连、超时与会话清理

- 状态：Proposed / 待 Core 确认
- 日期：2026-10-28
- 责任范围：Harness + Core 契约协作

## 背景
请求超时、Agent 断连、审批等待、会话关闭和 Core 崩溃不是同一种取消语义。客户端无法仅凭本地连接状态判断远端操作是否停止。

## 暂定建议
Harness 将请求状态区分为已发送/处理中/已确认/明确失败/结果未知（只在证据足够时细分）。对有副作用的未知结果不自动重试。会话关闭时清理本地监听器、队列与异步任务，避免旧事件更新新会话；不声称远端 Agent 已停止。

## Core 需要确认
超时与过期规则、Agent 断连后的执行行为、关闭会话的效果、取消接口、操作状态查询和幂等键支持。

## 验证
超时但服务端已执行、断连后重连、审批等待期间 Core 重启、关闭会话后旧事件到达、重复提交与清理泄漏测试。

## 重新评估条件
Core 增加可查询的操作生命周期、取消或幂等机制。
