# ADR-001：人工与 Agent 输入控制权

- 状态：Proposed / 待 Core 确认
- 日期：2026-10-28
- 责任范围：Harness + Core 契约协作

## 背景
人工输入与 Agent 输入可能在同一 Shell 上时间重叠。Harness 本地禁用按钮不能阻止其他客户端或服务端已排队的操作。

## 需要回答
1. 同一 Shell 的输入是否串行、按何种顺序处理？
2. 人工输入和 Agent 输入能否交错？
3. 是否存在 pause/cancel/interrupt/lock 等公开能力？其保证范围是什么？
4. 审批待处理时，Shell 及已排队命令是否继续运行？

## 候选方案
- A. 仅客户端提示与本地去重；不声称全局互斥。
- B. Core 提供可验证的服务端互斥/取消/抢占语义，Harness 通过公开接口调用。
- C. 混合方案：默认客户端提示，具备服务端能力时提供更强操作。

## 暂定建议
先采用 A；只有 Core 契约和测试证实后才启用 B/C 的对应功能。不得用 UI 锁伪装服务端互斥。

## 验证
并发输入测试、跨客户端测试、输入超时后状态核对、Agent 运行期间人工输入测试。

## 重新评估条件
Core 增加明确的输入仲裁、暂停或取消契约。
